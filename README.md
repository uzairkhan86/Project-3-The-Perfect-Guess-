# Number Guessing Game

This is a simple Python game.

The computer chooses a random number between 1 and 100.

The player has to guess the number.

The program tells the player:
- Too low
- Too high
- Correct

## What I learned

While making this project, I practiced:
- Python variables
- if / elif / else
- while loops
- user input
- random numbers

## How to play

Run the Python file and enter a number between 1 and 100.
